# Asus-control-center

ASUS laptop control center for Arch Linux, built specifically for my own device. It provides a convenient interface for managing and monitoring ASUS-specific hardware features, system settings, performance profiles, and other laptop controls that may not be available through standard Linux tools.




Project plan:
1. Hardware Information: display information about the system with a simple dashboard

2. ASUS-Specific Controls: Start controlling hardware. From keyboard lights to fan controls and gpu control.

3. Profiles: Create configurable profiles for different use cases, such as quiet, balanced, battery-saving, and performance modes.

4. GUI: Creating a simple GUI for easier use

5. Broader ASUS Compatibility: Expand support beyond my own laptop.
